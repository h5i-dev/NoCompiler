## Arr

An array of `n` elements of `w` bytes at `a`: element `i` is `w` bytes at `a + w * i`. It lies in the array, two different elements are disjoint, the next element is `w` further, a write to one element leaves the others, an element reads back what was written, and a write outside the array leaves every element. Namespace `NoCompiler.Lib`. Round 7, B's row.

- `arr_covers`: Element `i` of an array of `n` elements of `w` bytes at `a`: `a + w * i`.
- `arr_disjoint`: Two different elements of an array are disjoint.
- `arr_next`: The next element's address: `a + w * (i + 1) = (a + w * i) + w`.
- `arr_readLE_writeLE_other`: Reading element `j` after writing element `i ≠ j`.
- `arr_readLE_writeLE_same`: Reading element `i` just written (`w ≤ 8`).
- `arr_readLE_writeLE_outside`: A write outside the array leaves every element.

## Bits

## Div

- `div_magic`: Division by a constant as a multiplication and a shift: when `M * d = 2^N + e` with `e <= 2^(N-64)` (`N >= 64`), `x * M / 2^N = x / d` for every `x < 2^64`.

## Field

This is the shape of every "field after field" step of a libc proof (FILE, the stack frame, struct pthread). Namespace `NoCompiler.Lib`. Round 7, B's row.

- `disjoint_fields`: Two nonempty ranges at non-overlapping offsets from one base, neither past 2^64, are disjoint.
- `disjoint_base_field`: The base itself is offset 0.
- `readLE_writeLE_field`: Reading a field after writing another: the old value.
- `readBytes_writeLE_field`: The bytes of a field after writing another: the old ones.
- `read64_writeLE_field`: The word in a field after writing another: the old word.
- `read32_writeLE_field`
- `read8_writeLE_field`
- `writeLE_fields_comm`: Writes to two different fields commute.

## Loop
